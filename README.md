# Dokusho extensions

Published index of Dokusho web novel extensions. Built and pushed automatically by
[dokusho-extensions-source](https://github.com/Globeeeee/dokusho-extensions-source); do not edit by hand.

## Add to Dokusho

Settings → Browse → Extension repos → Add, then paste:

```
https://github.com/Globeeeee/dokusho-extensions/raw/repo/index.pb
```

## Files

| File | Role |
|------|------|
| `index.pb` | gzipped protobuf index, the URL the app reads |
| `index.json` | same data, readable |
| `repo.json` | repo name, website and APK signing key fingerprint |
| `index.html` | plain list of APK links |
| `icon/` | fallback icons |

APKs are attached to GitHub Releases of this repo, not committed to the branch.
